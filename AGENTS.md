# Commit Messages

All commits must be a single line following [Conventional Commits](https://www.conventionalcommits.org/), as concise as possible. Examples:

- `feat: implement Foo`
- `fix(feature): undo mistake`

Never add a signature, `Co-Authored-By` trailer, or any other co-commit/attribution info (including "Generated with ..." lines) to commits, PRs, or any other output. The individual piloting the agentic harness gets the credit, always.
